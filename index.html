SantaiSpace API Reference

Developer interface documentation for managing authentications, relationships, and user feeds.

1. Authentication Endpoints

POST /signup

Register a new user account with a securely hashed password.

Request Body

{
  "username": "johndoe",
  "email": "john@example.com",
  "password": "securepassword123"
}

Success Response (201 Created)

{
  "user_id": 1,
  "username": "johndoe",
  "email": "john@example.com"
}
POST /login

Authenticate credentials to fetch an access token and a refresh token.

Request Body

{
  "email": "john@example.com",
  "password": "securepassword123"
}

Success Response (200 OK)

{
  "token": "eyJhbGciOi...",
  "refreshToken": "eyJhbGciOi..."
}
POST /refresh

Exchange a valid long-lived refresh token for a fresh 15-minute access token.

Request Body

{
  "refreshToken": "eyJhbGciOi..."
}

Success Response (200 OK)

{
  "accessToken": "eyJhbGciOi..."
}
GET /whoami 🔒 Authenticated

Extracts and returns user identity metadata claims embedded in the current access token.

Headers

  • Authorization: Bearer <token>

Success Response (200 OK)

{
  "userId": 1,
  "username": "johndoe"
}

2. Friendship Endpoints

POST /friendships 🔒 Authenticated

Initiate a social connection request to another unique user id.

Request Body

{
  "receiverId": 2
}

Success Response (201 Created)

{
  "user_id_1": 1,
  "user_id_2": 2
}
PUT /friendships/:requestorId 🔒 Authenticated

Accept, decline, or update the status of an incoming or existing relationship connection request.

URL Parameters

  • requestorId (number) — The user ID of the person who initiated or belongs to the relationship.

Headers

  • Authorization: Bearer <accessToken>
  • Content-Type: application/json

Request Body

{
  "status": "accepted"
}

Success Response (200 OK)

{
  "user_id_1": 2,
  "user_id_2": 1,
  "status": "accepted"
}

Error Responses

// 404 Not Found
{ "error": "Friendship not found" }

// 500 Internal Server Error
{ "error": "Something went wrong" }

3. Post Endpoints

POST /posts 🔒 Authenticated

Create and store a new post entity bound to the authenticated user session.

Headers

  • Authorization: Bearer <token>
  • Content-Type: application/json

Request Body

{
  "title": "My Journey into Code",
  "content": "Exploring backend databases with Express and Postgres today!",
  "visibility": "Public"
}

Success Response (200 OK)

{
  "post_id": 42,
  "title": "My Journey into Code",
  "content": "Exploring backend databases with Express and Postgres today!",
  "visibility": "Public",
  "user_id": 1,
  "created_at": "2026-10-04T19:57:00.000Z"
}

Error Responses

// 404 Not Found
{ "error": "Post not inserted" }

// 500 Internal Server Error
{ "error": "Something went wrong" }
GET /posts 🔒 Authenticated

Retrieve a descending chronological timeline feed containing visible 'Public' posts and authorized 'Friends-only' items.

Headers

  • Authorization: Bearer <token>

Success Response (200 OK)

[
  {
    "post_id": 42,
    "title": "My Journey into Code",
    "content": "Exploring backend databases with Express and Postgres today!",
    "visibility": "Public",
    "created_at": "2026-10-04T19:57:00.000Z",
    "user_id": 1,
    "username": "johndoe"
  },
  {
    "post_id": 19,
    "title": "Weekend Plans",
    "content": "Hosting a small backyard barbecue for the team.",
    "visibility": "Friends-only",
    "created_at": "2026-10-03T14:20:00.000Z",
    "user_id": 2,
    "username": "janedoe"
  }
]

Error Responses

// 500 Internal Server Error
{ "error": "Something went wrong" }
